How to read this
  • Total = the database plus the folders the app writes to on the server. Dependencies (node_modules) only count if you tick the box above.
  • Deleted data does not shrink the database straight away. The space is reused first and returned to the disk when the database cleans up. "Dead rows" under each table show how much is waiting to be cleaned.
  • Free space fast: the biggest wins are usually user activity (clear old page views) and old generated documents.
  • System is what the database holds besides your tables: internal catalogs and bookkeeping.
